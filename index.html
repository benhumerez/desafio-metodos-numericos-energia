Modelo matemático: dE/dt = -kE

Fundamento matemático

Ecuación: E'(t) = -kE(t)

Solución exacta: E(t) = E₀e-kt

Heun: E(n+1) = E(n) + h(k1+k2)/2

RK4: E(n+1) = E(n) + h(k1+2k2+2k3+k4)/6

El error absoluto es |exacto - aproximado|. El error relativo porcentual es (error absoluto / |exacto|) × 100.
